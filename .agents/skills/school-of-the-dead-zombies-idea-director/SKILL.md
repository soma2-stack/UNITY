# School of the Dead Zombies Idea Director

Use this skill when I want ideas for my Unity game **School of the Dead**.

## Main Goal

Help me come up with gameplay ideas that feel like a classic round-based zombie survival game, but are still original to **School of the Dead**.

The game should feel inspired by wave survival, mystery weapons, perks, wall buys, power, Pack-a-Punch-style upgrades, doors, traps, objectives, map flow, and escalating zombie rounds.

Do not copy exact Call of Duty names, logos, perk names, map names, weapon names, sounds, UI, or copyrighted branding.

## What To Make Ideas For

Brainstorm ideas for:

* perks
* perk machines
* power-ups
* wall buys
* mystery box weapons
* weapon upgrade machines
* special zombie types
* boss rounds
* traps
* buildables
* map objectives
* easter egg steps
* door progression
* school-themed rooms
* scary school props
* player upgrades
* HUD/UI ideas
* round pacing
* zombie scaling
* sound and atmosphere
* death scene ideas
* survival rewards
* small features Claude or Codex can implement

## Style Direction

Ideas should fit:

* dark school zombie survival
* arcade horror
* useful but simple mechanics
* readable player upgrades
* round-based survival
* creepy but not overly complicated
* multiplayer-friendly systems
* Unity-friendly implementation
* beginner-friendly development steps

## Important Design Rules

* Keep ideas original.
* Do not use exact COD Zombies perk names.
* Do not rely on copyrighted characters, logos, songs, map names, or branding.
* Do not suggest huge systems first.
* Prefer ideas that can be built in small steps.
* Explain why each idea helps gameplay.
* Rank ideas by how useful and how hard they are to add.
* If an idea is too big, break it into a tiny first version.

## School of the Dead Priorities

Prefer ideas that improve:

1. Player survival
2. Zombie threat
3. Weapon variety
4. Map progression
5. Perks and upgrades
6. Mystery box excitement
7. Power/power switch goals
8. Pack-a-Punch-style weapon upgrading
9. Round pacing
10. Replayability

## Output Format For Brainstorming

When I ask for ideas, use this format:

### Best idea first

Give the strongest idea and explain why.

### Idea list

For each idea include:

* Name
* What it does
* Why it is useful
* How it feels in gameplay
* Easy version
* Harder upgraded version
* Difficulty: Easy / Medium / Hard
* Should build now: Yes / Later / No

### Best next feature

Pick the best one to build next.

### Tiny implementation plan

Break the idea into 3 to 5 small steps.

### Copy/paste prompt

Give me a clean prompt I can send to Claude or Codex to build only the tiny first version.

## Output Format For Feature Planning

When I choose one idea, use this format:

### Chosen feature

Name the feature.

### Tiny first version

Describe the smallest playable version.

### Files likely involved

Guess the likely Unity scripts or systems involved, but do not edit anything.

### What not to do yet

List things to avoid so the feature does not become too big.

### Test plan

Give simple Unity Play Mode test steps.

### Claude/Codex prompt

Give me one copy/paste prompt to implement it safely.
