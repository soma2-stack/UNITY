# School Of The Dead — Multiplayer Setup

Online 4-player co-op uses **Unity Netcode for GameObjects** + **Unity Relay**.
The code is already in the project; you just need to link it to a Unity Cloud
project once per developer machine.

---

## Step 1 — Link to a Unity Cloud Project

1. In Unity Editor: **Edit → Project Settings → Services**.
2. Click **Link to a Cloud Project** (or **Create a new project**).
3. Sign in with your Unity account if prompted.
4. Select (or create) your project — call it "SchoolOfTheDead" or anything you like.
5. Click **Link**.

The Project ID now appears in Project Settings → Services.

---

## Step 2 — Enable Authentication + Relay in the Dashboard

1. Open [cloud.unity.com](https://cloud.unity.com) and select your project.
2. Under **Products**, enable:
   - **Authentication** — handles anonymous sign-in (no account needed for players).
   - **Relay** — routes traffic between host and clients without port-forwarding.
3. Save / confirm. Both services are **free up to their included usage tier**.

---

## Step 3 — Verify it works in Play Mode

1. Open the **MainMenu** scene and hit Play.
2. The new "School Of The Dead" menu appears automatically.
3. Click **PLAY ONLINE** → enter any display name → click **HOST**.
4. If everything is linked correctly you'll see a 6-character **Join Code** appear.
5. A second machine (or a Multiplayer Play Mode virtual player) clicks **JOIN**,
   enters the code, and lands in the lobby roster.
6. Host clicks **START MATCH** → both clients load into `SchoolOfTheDead`.

> If hosting shows **"Unable to host: …"** check that Authentication and Relay
> are enabled in the dashboard and the Project ID is linked (Step 1–2).

---

## How host/join works

```
Host machine                    Join machine
-----------                     ------------
PLAY ONLINE                     PLAY ONLINE
→ HOST                          → enter 6-char code
← Join Code shown               → JOIN
                                ← appears in lobby roster
HOST: START MATCH ──────────────────────────────► both load SchoolOfTheDead
```

- Up to **4 players** total (1 host + 3 clients).
- The join code is valid until the host leaves the session.
- If a client disconnects during a match they have **120 seconds** to reconnect
  (RECONNECT button appears in the menu after a failed session).
- The host ending the session returns all clients to the Main Menu.

---

## Multiplayer Play Mode (solo testing on one machine)

Unity's **Multiplayer Play Mode** package (already in the project) lets you
simulate multiple players without extra machines.

1. **Window → Multiplayer Play Mode** → add virtual players.
2. Enter Play Mode — each virtual player gets its own view.
3. Host in the main Editor window, join in a virtual player window.

---

## In-game notes

- Each player gets a **unique survivor color** (green / tan / blue / red).
- Floating name tags appear above remote players.
- The local player's own body mesh is hidden (first-person view).
- Points, rounds, and zombie kills are tracked locally per-player for now;
  full server-authoritative sync is a future task.
- The `NetworkPlayer` prefab is auto-generated by the Editor on first import
  (`Tools → School of the Dead → Refresh Network Player Prefab` to rebuild it).
